The workflow

From intention to evidence.

A small loop that makes an AI-assisted change legible to both humans and machines.

01

Write intent

Make the change explicit.

Put the goal, files, artifacts, and validation commands in a versioned YAML manifest.

goal: "Add a feature"
files:
  edit:
    - src/service.py
validate:
  - pytest tests/
02

Build freely

Let the implementation evolve.

Use your agent, editor, and normal engineering tools while the contract stays stable.

maid-runner
$ implement the manifest
→ 3 artifacts declared
→ 4 validation commands
03

Prove the result

Verify the shape and behavior.

Run the MAID gates. Drift becomes visible before it becomes architecture.
